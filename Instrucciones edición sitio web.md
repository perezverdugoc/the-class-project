Revisa el sitio completo, con especial foco en `divulgacion/index.html`, pero también en todas las demás páginas HTML del proyecto.

Objetivo: eliminar advertencias del tipo `CSS inline styles should not be used, move styles to an external CSS`, sin alterar el diseño visual ni el comportamiento del sitio.

Instrucciones específicas:

1. Busca todos los estilos inline del tipo `style="..."` dentro de los archivos `.html`.  
2. Migra esos estilos al archivo central de estilos del proyecto: `css/styles.css`.  
3. Reemplaza cada `style="..."` por clases CSS semánticas y reutilizables.  
4. Si un estilo es único de una sección, crea una clase específica con nombre claro.  
5. Si el mismo patrón visual se repite en varias páginas, crea una clase reutilizable.  
6. No elimines ningún estilo sin migrarlo correctamente.  
7. No cambies textos, enlaces, imágenes, rutas, estructura de contenido ni jerarquía semántica salvo que sea estrictamente necesario para aplicar clases.  
8. Mantén intacto el diseño actual: tamaños, márgenes, colores, espaciados, bordes, alineaciones, sombras, anchos y comportamiento responsive.  
9. Revisa especialmente las páginas dentro de carpetas como:  
   * `divulgacion/index.html`  
   * `encuesta/index.html`  
   * `equipo/index.html`  
   * `proyecto/index.html`  
   * `accountability/index.html`, si existe (esta página debiese ser `transparencia/index.html)`  
   * cualquier otro `index.html` del proyecto  
10. Antes de editar, identifica cuántos estilos inline existen y en qué archivos.  
11. Después de editar, verifica que:  
* no queden estilos inline innecesarios;  
* el archivo `css/styles.css` siga cargando correctamente desde cada página;  
* las rutas relativas no se rompan;  
* el sitio mantenga la misma apariencia visual.  
12. Si alguna página usa una ruta distinta para cargar el CSS, corrígela solo si está mal, cuidando la profundidad de carpetas. Por ejemplo:  
* desde una página en carpeta interna: `../css/styles.css`  
* desde la raíz: `css/styles.css`  
13. No hagas refactorizaciones grandes ni reordenamientos innecesarios. Solo limpia los estilos inline y consolida el CSS.  
14. Al final, entrégame un resumen breve con:
